### Agent 2: Rewrite `_conventionsRef` (conventions.md)
**Issues**: #21, #33, #34, #36, #38, #41, #42, #43
**File**: `lib/src/cli/commands/skills_command.dart` — function `_conventionsRef`

Add behavioral rules:
- **IntrinsicHeight**: Cards in same Row need IntrinsicHeight + CrossAxisAlignment.stretch
- **Never add wrappers not in Figma**: Before adding Container/Card, verify it exists as a Figma node
- **Never blanket-apply style changes**: Scope each fix to specific component, verify others unaffected
- **Never guess, verify**: ALWAYS check Figma design context for actual values. Never assume.
- **Copy-paste node names**: Don't retype Figma node names, copy exactly
- **Never remove functionality as workaround**: Find alternative implementation (e.g. TweenAnimationBuilder instead of removing AnimatedDefaultTextStyle)
- **Ask before uncertain color changes**: When design context is ambiguous, show user what you plan and ask BEFORE changing code
- **Generate after EACH visual change**: Don't batch multiple visual changes, verify each one individually
- **Save novel solutions to CLAUDE.md**: When a new pattern is discovered, persist it

### Agent 4: Rewrite `_figmaClaude` (main figma skill template)
**Issues**: #1-4, #10, #24, #26, #27, #30, #37, #40
**File**: `lib/src/cli/commands/skills_command.dart` — function `_figmaClaude`

Add to the workflow steps:
- **Color extraction workflow**: After getting design context, extract ALL bg-[...] and text-[color:...] values. Create color mapping table BEFORE writing code. Map each Figma token to project DS token.
- **DS token enforcement**: NEVER use hardcoded Color(). Always use DS tokens. If no token exists, flag to user.
- **Positive/negative value coloring**: Values with "-" prefix → red (contentNegativeBold), "+" prefix → green (contentPositive). Universal financial UI pattern.
- **Completeness check**: List ALL sections visible in Figma, check each exists in implementation, flag missing ones.
- **Reference image enforcement**: MUST save reference image to .reference/ dir. Not optional.
- **Large design context**: Warn about 100K+ char responses, suggest fetching sub-nodes.
- **Exact character matching**: Copy exact chars from Figma (breadcrumb separators, currency symbols, etc.)
- **Padding extraction**: Search for gap-[], p-[], px-[], py-[] in design context. Map to Flutter EdgeInsets. Check shell, content, and card padding separately.
- **SVG icon weight consistency**: MaterialIcons have thick strokes, SVG icons thin. Create SVGs with stroke-width 1.2-1.5.
- **Save patterns to CLAUDE.md**: When novel solution found, save to project memory.

Also update `_figmaCursor` and `_figmaCodex` with the same core principles (shorter form).
