# Print Widget Preview

VS Code extension for previewing and comparing Flutter widget screenshots generated by [print_widget](https://pub.dev/packages/print_widget).

## Features

### Screenshot Sidebar
Browse all generated screenshots in a tree view, grouped by feature name, state, and device.

### Single Image Preview
Click any device node to open a full preview with device info and dimensions.

### Multi-Device Comparison
Right-click a feature to view all device variants side-by-side in a responsive grid.

### Before/After Diff
Compare two screenshots with a draggable slider overlay. Useful for reviewing visual changes between iterations.

### Design Reference Comparison
Compare a generated screenshot against a design reference image (Figma export, mockup, etc.) with:
- Pixel-level diff visualization (differences highlighted in red)
- Similarity percentage with color-coded score
- Adjustable sensitivity threshold

The extension auto-detects `.reference/` images saved by AI skills — no manual file picking needed.

### Go to Source
Jump to the widget's definition in your `print_config.dart` file.

## How it works

The extension reads `manifest.json` generated by `print_widget generate` and builds a tree view from the entries. It watches the output directory for changes and auto-refreshes.

## Reference images

When using the print_widget Figma skill, reference images are saved to:

```
<output_dir>/<name>/.reference/<device>.png
```

The extension detects these automatically. If no reference image exists, a file picker is shown instead.

## Installation

### From source (all platforms)

**1. Build the VSIX package:**

```bash
# Clone and build
git clone https://github.com/ulisseshen/print_widget.git
cd print_widget/extensions/vscode
npm install
npm run build
npx @vscode/vsce package
```

This creates `print-widget-preview-0.1.0.vsix`.

**2. Install the VSIX:**

```bash
code --install-extension print-widget-preview-0.1.0.vsix
```

Or in VS Code: `Ctrl+Shift+P` (Windows/Linux) / `Cmd+Shift+P` (Mac) → "Extensions: Install from VSIX..." → select the `.vsix` file.

### AI-assisted installation

If you're using Claude Code, Cursor, or another AI assistant, ask it to run:

```bash
# macOS / Linux
cd <print_widget_repo>/extensions/vscode && npm install && npm run build && npx @vscode/vsce package && code --install-extension print-widget-preview-*.vsix

# Windows (PowerShell)
cd <print_widget_repo>\extensions\vscode; npm install; npm run build; npx @vscode/vsce package; code --install-extension print-widget-preview-*.vsix
```

### Platform notes

#### macOS

The `code` CLI is available if you installed VS Code normally. If not, open VS Code → `Cmd+Shift+P` → "Shell Command: Install 'code' command in PATH".

#### Linux

The `code` command is available after installing VS Code via apt, snap, or the .deb/.rpm package. For Snap installs, the command may be `code` or `snap run code`.

#### Windows

The `code` command is added to PATH during VS Code installation (check "Add to PATH" during setup). If not available, use the full path:

```powershell
# PowerShell
& "$env:LOCALAPPDATA\Programs\Microsoft VS Code\bin\code.cmd" --install-extension print-widget-preview-0.1.0.vsix
```

Or install via the VS Code GUI: Extensions sidebar → `...` menu → "Install from VSIX...".

### Verify installation

After installing, open a Flutter project with print_widget configured and run:

```bash
print_widget generate
```

The Print Widget icon appears in the VS Code activity bar (left sidebar).

## Requirements

- VS Code 1.85.0 or later
- Node.js 18+ and npm (to build from source)
- A Flutter project with print_widget configured
- Generated screenshots (run `print_widget generate`)
